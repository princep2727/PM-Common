# PM Commons - The Operating System for Project Managers

![PM Commons Banner](https://img.shields.io/badge/PM%20Commons-Project%20Operating%20System-indigo?style=for-the-badge&logo=react)

**PM Commons** is a high-performance, all-in-one workspace designed to elevate the careers of Project Managers. Built with a "Fintech" aesthetic, it combines real-time intelligence, community insights, and AI-powered tools into a seamless, data-dense interface.

🚀 **Live Demo**: [https://pm-commons.web.app](https://pm-commons.web.app)

## ✨ Features

### 🧠 **AI Career Coach**
- **Mock Interviews**: Real-time voice/text simulations with Gemini-powered AI.
- **Instant Feedback**: Detailed grading on project execution, leadership, and stakeholder management.
- **Custom Scenarios**: Practice for specific roles (e.g., Technical Program Manager, Scrum Master).

### 💼 **Job Board 2.0**
- **Curated Listings**: Real-time feed of PM roles from top tech companies.
- **Smart Filters**: Sort by remote/hybrid, salary range, and experience level.
- **Track Applications**: Built-in status tracking for your job hunt.

### 🛠️ **Productivity Tools**
- **Pomodoro Timer**: Focus timer optimized for deep work sessions.
- **Resources Library**: Curated templates, frameworks (RICE, CIRCLES), and reading lists.
- **Task Manager**: Kanban-style board for managing daily priorities.
- **Quiz**: Test your PM knowledge with daily trivia.

### 🌐 **Community & News**
- **PM News Feed**: Aggregated updates from TechCrunch, Product Hunt, and more.
- **Discussions**: Connect with other PMs to share insights and advice.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/princep2727/PM-Common.git
   cd PM-Common
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Environment Variables**
   Create a `.env` file in the root directory and add your Firebase and Gemini keys:
   ```env
   VITE_FIREBASE_API_KEY=your_api_key
   VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=your_project_id
   VITE_GEMINI_API_KEY=your_gemini_key
   ```

4. **Run Locally**
   ```bash
   npm run dev
   ```
